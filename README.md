# Trabajo IPO — Gestión de complejo turístico rural (Curso 2026/2027)

Este repositorio está organizado por carpetas independientes para que cada integrante pueda incluir y presentar su versión del prototipo WPF de forma separada para su revisión:

  - Solución de Visual Studio: [`Version_Javier/Trabajo_IPO.sln`](Version_Javier/Trabajo_IPO.sln)

## Cómo ejecutar la versión actual (`Version_Javier`)

1. Abrir `Version_Javier/Trabajo_IPO.sln` en Visual Studio 2022 (carga de trabajo *Desarrollo de escritorio .NET*, .NET Framework 4.7.2).
2. Compilar y ejecutar con `F5` o `Ctrl+F5` (o ejecutar directamente `Version_Javier/bin/Debug/Trabajo_IPO.exe` tras compilar).
3. Iniciar sesión con cualquiera de las credenciales de prueba (`admin` / `camping2026`, `javier` / `ipo2026` o `recepcion` / `bienvenido`).
